# AGY adapter contract — post-update validation

Evidence: `agy update` confirmed AGY **1.2.16** was the latest offered version on 2026-10-05, then a fresh five-call group passed with `gemini-3.8-flash-low` and process-only `AGY_CLI_DISABLE_AUTO_UPDATE=true`. Source commit `9a30e0774de09e0815c4fc5caf456472f8fc3509`. These findings apply to the recorded version and model.

- **Invoke:** `agy -p <prompt> --model <id> --output-format stream-json --print-timeout <duration> --add-dir <workspace>`. `--conversation <id>` resumes; omitting it creates a new session. This run used `--dangerously-skip-permissions`; restricted enforcement remains unverified.
- **Session capture:** persist `event.conversation_id ?? event[event.event]?.conversation_id`. In the observed `init`, the session ID is top-level, not inside `init`. Job/session keys must include backend, and continue/restart must preserve the original backend and cwd.
- **Events:** retain the original NDJSON; normalize `init`, `step_update` and `result` independently from process supervision. Tool steps use `step_type=tool`, `tool_name`, `tool_info`, `state` and `step_index`; response steps use `step_type=agent_response` and `text_delta`. Preserve unknown types and never invent a completion event.
- **Result:** preserve native `status`, `error`, `response`, `structured_output`, `conversation_id`, native usage/counters and process exit separately. For schema requests, use `structured_output` as the machine result. In this sample `response` contained extra `toolAction`/`toolSummary` keys while `structured_output` held the requested fields.
- **Cancellation:** the real stopped-shell stream ended in `result.status=ERROR`, `error=interrupted`. The companion's own cancellation request produced canonical `canceled`, reason `canceled`, wait exit 4. Determine cancellation from our owned job lifecycle, not by treating any backend ERROR as canceled. No synthetic native `canceled` event belongs in fixtures.
- **Recovery:** an explicit conversation resumed successfully after cancel and recalled a random earlier nonce without the nonce in the new prompt and with no observed tool events. Reject concurrent follow-up on an active native session; a fresh restart must not masquerade as native continuation.
- **Supervision:** reuse atomic state, locking, durable terminal reporting, cancellation request channel and PID birth-identity checks. Stop only this invocation's owned execution tree. Successful AGY cleanup does not prove ownership of a Grok shared leader or another backend's remote tools.
- **Telemetry:** native duration/turn/token values can reflect the whole conversation; the final nonce result reported about 106.4 seconds while that invocation's measured wall time was about 50.2 seconds. Record independent per-invocation wall time. Mark provider usage scope `conversation` or `unknown` rather than charging it as a fresh-turn total.
- **Output separation:** store structured machine results independently from human headings/diagnostics/workspace warnings. Keep observer artifacts outside the worktree or in a pre-excluded metadata directory. A git-status delta is a change signal, not attribution to one agent or proof of unchanged already-dirty contents.
- **Capabilities not established:** restricted/write denial, hard no-tools enforcement, hard-timeout cleanup, independent parallel sessions, Windows and other versions/models. A no-tool prompt with zero tool events is an observed behavior, not a security boundary.

Offline contract assertions: `node check-fixtures.mjs`. No model call or global configuration change occurs. Active fixtures are the final post-update run; the initial baseline remains in `../fixtures/agy/history/pre-update-v1.2.16`. Later versions need separately recorded live evidence.
